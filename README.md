# Telecom customer churn analysis

## Project overview

This project explores customer churn in the telecommunications industry using Python and exploratory data analysis. The aim is to identify customer behaviours, patterns and factors associated with churn and translate the findings into actionable business insights.

## Tools and technologies

- Python
- Pandas and NumPy
- Matplotlib
- Jupyter Notebook

## Analysis

- Data quality assessment and validation
- Customer churn analysis and segmentation
- Customer lifetime value analysis
- Identification of high risk customer profiles
- Exploratory customer risk scoring

## Key findings

- Customers on month to month contracts showed the highest churn rate.
- Customers with shorter tenures were more likely to churn.
- Customers without online security or technical support showed higher churn rates.
- The combination of month to month contracts, electronic cheque payments and fibre optic internet had a churn rate of approximately 60%.
